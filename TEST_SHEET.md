# 📋 Тестовый лист матрицы ErgoDox (Диагностика клавиш)

> **Как пользоваться этим документом:**
>
> 1. Откройте этот файл в редакторе (в IDE или текстовом редакторе).
> 2. Поставьте курсор внутрь скобок `[     ]` нужной клавиши.
> 3. Нажмите соответствующую **физическую клавишу** на клавиатуре.
> 4. Клавиатура сама напечатает код координаты (например, `L00 ` для левой или `R05 ` для правой).
>
> _Если при нажатии ничего не напечаталось — оставьте скобки пустыми или напишите `[ ОБРЫВ ]`._

### 1.1. Визуальная схема клавиш (Основной блок)

Поставьте курсор в скобки и нажмите соответствующую кнопку:

```text

[ Esc/Тильда:       ] [ 1:              ] [ 2:              ] [ 3:              ] [ 4:              ] [ 5:              ] [ Delete (внутр.):  ]

Ряд 1 (Верхние буквы):
[ Tab:              ] [ Q:              ] [ W:              ] [ E:              ] [ R:              ] [ T:              ] [ Верт. верхняя:    ]

Ряд 2 (Средний ряд / Home):
[ Caps Lock:        ] [ A:              ] [ S:              ] [ D:              ] [ F:              ] [ G:              ] [ Верт. нижняя:     ]

Ряд 3 (Нижние буквы):
[ Shift левый:      ] [ Z:              ] [ X:              ] [ C:              ] [ V:              ] [ B:              ]

Ряд 4 (Нижний ряд модов):
[ Мод 1 (крайний):  ] [ Мод 2:          ] [ Мод 3:          ] [ Мод 4:          ] [ Мод 5 (внутр.): ]
```

## ⚡ Комбинации для входа в Bootloader (без пинцета)

Если нужно снова прошить плату:

- **Левая половина**: зажмите одновременно клавиши **`Esc`** и **`Delete`** (крайние клавиши верхнего ряда).
- **Правая половина**: зажмите одновременно клавиши **`Backspace`** и **`-`** (крайние клавиши верхнего ряда).
